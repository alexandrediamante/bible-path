# PWA icons

The release icons in `pwa/` are original Bible Path artwork generated by `tool/generate_icons.py`:

- `icon-32.png` — browser favicon;
- `icon-180.png` — iOS Add to Home Screen;
- `icon-192.png` and `icon-512.png` — web app manifest.

The open page and single rising path were drawn specifically for this project. The artwork stays inside the maskable safe area, so the 192px and 512px files are declared as both `any` and `maskable`.

Other platform icon directories are retained only as unverified local source material. They are not referenced by the v1 PWA and must not be published without provenance.
